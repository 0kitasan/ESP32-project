## Mate Float

搭载浮力引擎的浮标，通过泵吸水/排水改变重量实现上浮和下潜

比赛任务：

- 在水面发送任务指令后，开始任务，任务过程中上位机不再发送任何指令
- 下潜至2.5m，保持30s
- 上浮至0.4m，保持30s
- 浮出水面回传历史深度数据

## 调试

目前处于调试阶段，需要：

- 岸上通过 MQTT 下发目标深度命令（附带控制器参数等）
- 浮标收到命令后开始下潜
- 任务运行设定时长后直接强制上浮（防止调试时间过长）
- 浮出水面后再通过 MQTT 回传历史深度数据

FloatManager和StorgeDriver暂时是没用的

## MQTT Tool

- MQ3T，可以方便查看历史数据
- MQTT链路：broker均为上位机的`Mosquitto`
  - 在实验室，esp32与上位机均连接实验室路由器
  - 在比赛时，esp32连接笔记本热点，MQ3T连接`192.168.137.1`
