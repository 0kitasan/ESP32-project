## Mate Float

搭载浮力引擎的浮标，通过泵吸水/排水改变重量实现上浮和下潜

比赛任务：

- 在水面发送任务指令后，开始任务，任务过程中上位机不再发送任何指令
- 下潜至1.1m，保持30s
- 上浮至0.4m，保持30s
- 浮出水面回传历史深度数据

## 当前实现

目前主线已经切到正式 `Mission` 状态机：

- 岸上通过 MQTT 下发正式任务开始命令
- 第 1 段下潜至 `1.1 m` 并悬停 `30 s`
- 第 2 段上浮至 `0.4 m` 并悬停 `30 s`
- 随后强制上浮
- 浮出水面后按比赛格式回传历史数据包

原先的 `FloatManager` 已经被 `Mission` 替代，`debugDepthMission(...)` 作为单目标调试入口保留。

## MQTT Tool

- MQ3T，可以方便查看历史数据
- MQTT链路：broker均为上位机的`Mosquitto`
  - 在实验室，esp32与上位机均连接实验室路由器
  - 在比赛时，esp32连接笔记本热点，MQ3T连接`192.168.137.1`
